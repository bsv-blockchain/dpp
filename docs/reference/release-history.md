# Release history

Maintainers and auditors checking an older installation can use this catalogue to find its exact release declaration and receipt for upgrades, verification and audit. For a new implementation, choose the [current set](release-sets.md#the-current-set), whose [beta.11 receipt](beta-11-publication.md) records its publication. Each archived receipt records the packages, source revision and verification steps for that publication.

## Earlier sets

Each earlier set is superseded, and each link opens its JSON at a recorded revision. For the beta.2 to beta.8 sets that is the source revision their approved plans bound, the revision to reproduce those plans from.
